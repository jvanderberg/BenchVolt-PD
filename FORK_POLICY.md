# Fork-only development policy

The original [`sydundar/BenchVolt-PD`](https://github.com/sydundar/BenchVolt-PD)
repository is read-only reference material for this work.

Never submit a pull request, issue, discussion, or push to the original
repository. All development branches and GitHub writes must target the
[`jvanderberg/BenchVolt-PD`](https://github.com/jvanderberg/BenchVolt-PD) fork.

Before any GitHub write, verify that the destination repository owner is
`jvanderberg`.
